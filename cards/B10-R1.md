## R1 release 忽略退出码（已修）

- 病根：`release.mjs#publicCheck()` 只看 `check-distribution --json` 的 `verified:true`，**不看子进程退出码** ⇒ 「exit 非零却自报 verified」会被当真。
- 修法：`verified = exit === 0 && parsed.verified === true`；`exit` 照实记入 `distribution.check`。
- 负向控制（`B10R1-controls.mjs`）：
  - A 公模式 + `exit=1` + JSON `verified:true` ⇒ `distribution.verified=false`（exit 如实 1）；
  - B 反空转：`exit=0` + `verified:true` ⇒ `distribution.verified=true`（不是“修成永远 false”）。

## R2 把 AUTO 当整卡 PASS（已修）
